# CLEANUP-001 — Xóa user test

| Trường | Nội dung |
|---|---|
| Feature | Cleanup |
| Priority | High |
| Loại coverage | Manual coverage mới |
| Trạng thái | Not Run |

## Tiền điều kiện

- Admin đăng nhập.
- User test có thể tồn tại.

## Dữ liệu test

Username mang tiền tố `E2E-MANUAL-`.

## Bước thực hiện

1. Vào Admin → User Management.
2. Tìm chính xác user test.
3. Xóa user và xác nhận.
4. Tìm lại username.

## Kết quả mong đợi

User test không còn trong kết quả. Không xóa bất kỳ user không mang tiền tố test.

## Cleanup

Hoàn tất cleanup user.
